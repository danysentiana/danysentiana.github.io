# 🌐 My Portfolio Website

A modern, responsive portfolio website built with **React**, **TypeScript**, and **Tailwind CSS**. This site showcases my projects, tech stack, and background as a developer.

## 🚀 Features

- ✨ Smooth scroll navigation and dark mode toggle
- 📂 Dynamic project listing with filtering and pagination
- 🖼️ Custom-built components with clean, responsive design
- ⚙️ Tech stack icons using `simple-icons`
- 🔍 SEO-friendly and mobile optimized

## 🛠️ Built With

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Vite](https://vitejs.dev/) – lightning-fast dev environment
- [Simple Icons](https://simpleicons.org/) – for tech logos
- [Shadcn UI](https://ui.shadcn.com/)
- [Lenis](https://lenis.darkroom.engineering/)
